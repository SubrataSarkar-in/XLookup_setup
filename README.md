## 🚀 What Is the XLOOKUP Function?

XLOOKUP is a lookup function in Microsoft Excel that searches for a value in one range and returns a corresponding value from another range.

Unlike VLOOKUP, which traditionally searches only from left to right and relies on a column index number, XLOOKUP allows you to specify separate lookup and return ranges. This makes lookup formulas more flexible, readable, and easier to maintain.

## 💡 Why Is XLOOKUP Better Than VLOOKUP?

   * Left and right lookups: Return values from columns on either side of the lookup range.
   * No column index required: Specify the return range directly instead of counting column numbers.
   * Exact match by default: Reduces the risk of accidental approximate matches.
   * Custom not-found results: Display a meaningful message when no match is found.
   * Multiple match modes: Support exact matches, approximate matches, and wildcard matching.
   * Flexible search direction: Search from the first item to the last or in reverse order.
   * More maintainable formulas: Inserting or rearranging columns is less likely to break the lookup logic.

## 🧮 XLOOKUP Syntax

The standard Excel XLOOKUP syntax is:
<br/>

| Argument | Description |
|---|---|
| <b> Lookup_value </b> | The value you want to find. |
| <b> Lookup_Array </b> | The range or array where Excel searches for the value. |
| <b> Return_array </b> | The range or array from which the matching result is returned. |
| <b> [if_not_found] </b> | Optional. The result to return if no match is found. |
| <b> [match_mode] </b> | Optional. Specifies exact, approximate, or wildcard matching. |
| <b> [search_mode] </b> | Optional. Specifies the search direction and supported search method. |
